# pwd

- 현재 디렉토리 경로를 출력합니다.

# cd

- 현재 디렉토리를 변경합니다.
- `cd ..` : 상위 디렉토리로 이동합니다.
- `cd ~` : 홈 디렉토리로 이동합니다.

# ls

- 현재 디렉토리의 파일 목록을 출력합니다.
- `ls -l` : 파일의 상세 정보를 출력합니다.
- `ls -a` : 숨김 파일을 포함한 모든 파일을 출력합니다.

# mkdir

- 새로운 디렉토리를 생성합니다.
- `mkdir <디렉토리명>` : 지정한 이름의 디렉토리를 생성합니다.

# rmdir

- 빈 디렉토리를 삭제합니다.
- `rmdir <디렉토리명>` : 지정한 이름의 빈 디렉토리를 삭제합니다.

# 파일 생성

- macOS에서는 `touch <파일명>` 명령어로 빈 파일을 생성할 수 있습니다.
- Windows에서는 `echo. > <파일명>` 명령어로 빈 파일을 생성할 수 있습니다.
- Linux에서는 `touch <파일명>` 명령어로 빈 파일을 생성할 수 있습니다.

# cp

- 파일이나 디렉토리를 복사합니다.
- `cp <원본> <대상>` : 파일 복사
- `cp -r <원본디렉토리> <대상디렉토리>` : 디렉토리 전체 복사

# mv

- 파일이나 디렉토리를 이동하거나 이름을 변경합니다.
- `mv <원본> <대상>` : 파일 이동 또는 이름 변경

# rm

- 파일이나 디렉토리를 삭제합니다.
- `rm <파일명>` : 파일 삭제
- `rm -r <디렉토리명>` : 디렉토리와 그 안의 파일 전체 삭제

# cat

- 파일의 내용을 출력합니다.
- `cat <파일명>` : 파일 내용 전체 출력

# less

- 파일의 내용을 페이지 단위로 출력합니다.
- `less <파일명>` : 파일을 스크롤하며 확인

# head / tail

- 파일의 앞부분 또는 뒷부분을 출력합니다.
- `head <파일명>` : 파일의 앞부분 출력
- `tail <파일명>` : 파일의 뒷부분 출력

# clear

- 터미널 화면을 깨끗하게 지웁니다.
- `clear` : 터미널 화면 초기화

# Ctrl + C

- 실행 중인 명령어를 강제 종료합니다.

# React 렌주룰 오목 게임 프로젝트

React를 학습하기 위한 렌주룰 적용 오목(Renju Omok) 게임 프로젝트입니다.

## 🚀 시작하기

### 설치 및 실행

1. 의존성 설치

```bash
npm install
```

2. 개발 서버 시작

```bash
npm run dev
```

3. 브라우저에서 http://localhost:5173 접속

### 빌드

```bash
npm run build
```

## 🎮 렌주룰 게임 방법

### 기본 규칙

1. 흑돌(첫 번째 플레이어)부터 시작합니다
2. 번갈아가며 교차선 위에 돌을 놓습니다
3. **정확히 5개**의 돌을 연속으로 놓는 플레이어가 승리합니다
4. "게임 다시 시작" 버튼으로 새 게임을 시작할 수 있습니다

### 렌주룰 금수 (흑돌에게만 적용)

- **3-3 금수**: 동시에 두 개 이상의 활삼(양쪽이 열린 3)을 만드는 수
- **4-4 금수**: 동시에 두 개 이상의 사(4개 연속)를 만드는 수
- **장목 금수**: 6개 이상 연속으로 놓는 수
- 백돌에게는 금수가 적용되지 않습니다

### 금수 예시

```
3-3 금수 예시:
○●○●○
　●○●　
○●○●○

4-4 금수 예시:
●●●●○
　　○　　
●●●●○

장목 금수 예시:
●●●●●●○ (6개 이상)
```

## 📚 학습 내용

- React useState Hook을 활용한 상태 관리
- 2차원 배열을 이용한 게임 보드 구현
- 복잡한 게임 로직 구현 (렌주룰 금수 검사)
- 이벤트 핸들링과 조건부 렌더링
- CSS를 활용한 반응형 UI 디자인
- 알고리즘 구현 (8방향 탐색, 패턴 매칭)

자세한 학습 가이드는 `PRACTICE.md` 파일을 참고하세요.

## 🎯 주요 기능

- ✅ 15x15 오목 게임 보드 (교차선 위에 돌 배치)
- ✅ 플레이어 턴 관리 (흑돌/백돌)
- ✅ 정확한 승리 조건 검사 (5목)
- ✅ **렌주룰 금수 검사**
  - 3-3 금수 (활삼 중복)
  - 4-4 금수 (사 중복)
  - 장목 금수 (6목 이상)
- ✅ 실시간 금수 경고 메시지
- ✅ 게임 재시작 기능
- ✅ 반응형 디자인
- ✅ 상세한 렌주룰 설명

## 🧠 알고리즘 특징

### 금수 검사 알고리즘

1. **방향별 연속 카운팅**: 8방향으로 연속된 돌의 개수 계산
2. **막힘 상태 검사**: 양쪽 끝의 막힘 여부 확인
3. **패턴 매칭**: 3-3, 4-4, 장목 패턴 검출
4. **실시간 검증**: 돌을 놓기 전 금수 여부 미리 체크

### 성능 최적화

- 불필요한 계산 최소화
- 효율적인 방향 탐색
- 조건문 최적화

## 🏆 렌주룰의 의미

렌주룰은 오목 게임의 균형을 맞추기 위해 도입된 규칙입니다:

- **선공(흑돌)의 과도한 유리함** 제한
- **게임의 깊이와 전략성** 향상
- **공정한 경기** 보장

## 📝 실습 문제

### 문제 1: 컴포넌트 분리

현재 모든 코드가 `App.jsx`에 있습니다. 다음과 같이 컴포넌트를 분리해보세요:

- `Board` 컴포넌트: 게임 보드만 담당
- `Cell` 컴포넌트: 개별 셀 담당
- `GameInfo` 컴포넌트: 게임 정보 표시
- `GameControls` 컴포넌트: 게임 컨트롤 버튼들

### 문제 2: 커스텀 Hook 만들기

`useOmokGame`이라는 커스텀 Hook을 만들어서 게임 로직을 분리해보세요.

```javascript
function useOmokGame() {
  // 게임 상태와 로직을 여기에 구현
  return {
    board,
    currentPlayer,
    winner,
    handleCellClick,
    resetGame,
  };
}
```
